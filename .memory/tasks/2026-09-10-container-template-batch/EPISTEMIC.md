# Current model

## Objective and artifact

This case prepares receiver-bound replay inputs for every remaining bottle and pitcher row in the source Lance v5 dataset: bottle rows 20–30 and pitcher rows 32,33,34,35,37,38,39. The artifact is `patches/full_containers/`, generated by `tools/build_full_container_receiver_patches.py`; it is not a claim of physical replay success.

## Supported mechanism

The verified bottle donor fixes failed acquisition by following an object-relative open approach, closing only after arrival, applying late tilt/return corrections, and restoring release/withdrawal. Because bottle orientation varies, donor-local geometry alone can place the hand on the wrong face. Each receiver therefore compares the specified `receiver_initial^-1 * donor_initial` alignment with direct receiver-local geometry in world space against its recorded hand approach; the higher-cosine candidate is recorded in the patch. All edited bottle phases are retimed to the receiver movement interval while the receiver object path is left unmodified.

The verified pitcher donor requires frozen 28-DoF targets because its 1.28 kg load creates wrist sag under the pinned servo. The reusable part is the donor target residual relative to its edited reference, not raw target coordinates. Each receiver command is its phase-resampled reference plus that donor residual, with 0–39 retained exactly from the receiver source. The monotonic map ends at the receiver movement endpoint and retains the donor's held release residual against that endpoint, including thumb-clear then sideways exit.

## Evidence and limits

The CPU decoder shows all 18 receivers share the intended object type and a 180-step approach prefix but have different movement durations and initial yaw. The generator validates UUID provenance, source frame count, active object, command hash/shape/finite values, monotonic valid reference mapping, patch solver settings, exact file inventory, receiver command prefix, and bottle object-path/prefix retention. See OPS.md.

The remaining uncertainty is contact physics: receiver geometry can alter collision, grasp closure, pitcher load compensation, lift, tilt, and release. Parent GPU replay is the discriminating experiment; no success claim is justified until that replay observes the intended object behavior.
